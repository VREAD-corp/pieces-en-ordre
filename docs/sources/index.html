Méthode

Les 30 listes de pièces (Maroc, Algérie, Tunisie, Sénégal, Côte d’Ivoire, Cameroun ; visite familiale, tourisme, voyage professionnel, stage salarié, stage étudiant) ont été lues dans l’Assistant visa de France-Visas le 13/10/2026 avec ces réponses : nationalité et résidence dans le pays, 35 ans, passeport ordinaire, court séjour, destination France métropolitaine, ni conjoint de Français ni membre de famille d’un Européen. Le texte officiel est reproduit tel quel ; les explications « Pourquoi on vous la demande » sont de nous et renvoient au code des visas. Les contenus de France-Visas sont publiés sous licence etalab-2.0.

Une erreur, un changement de liste ? Écrivez à octave@vread.fr.
