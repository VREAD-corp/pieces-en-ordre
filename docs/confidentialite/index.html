Ce que nous ne collectons pas

Aucun document, aucun numéro de passeport, aucune date de naissance, aucun nom de voyageur. Les listes fonctionnent dans votre navigateur : les cases cochées sont gardées sur votre appareil (stockage local du navigateur) et ne nous sont jamais envoyées. Aucun cookie, aucun traceur publicitaire.

Mesure d’audience anonyme

À chaque page vue et à quelques clics (choix d’une liste, impression, bouton du Pack), le navigateur envoie un compteur sans identifiant : page, événement, site d’origine, paramètres de campagne, type d’écran (mobile ou ordinateur), variante de prix affichée. Ces compteurs sont additionnés par jour dans un tableur Google (Google LLC, sous-traitant) ; votre adresse IP n’y est pas enregistrée. Rien n’est envoyé si votre navigateur active « Do Not Track » ou « Global Privacy Control ». Les robots d’indexation et les navigateurs automatisés, reconnus dans votre navigateur sans que leur signature soit transmise, sont comptés à part ; une page préchargée n’est comptée que si vous l’ouvrez. Base légale : intérêt légitime (mesurer l’usage du service), sans consentement nécessaire car aucune information n’est lue ni déposée sur votre appareil à cette fin.
